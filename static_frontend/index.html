Loewe Additivity & High-Throughput Checkerboard Screening

A reference framework for pharmacodynamic synergy and combination therapy evaluation

The Loewe Equation

The Loewe Additivity Model computes the Combination Index (CI) as:

CI = (dA / DA) + (dB / DB)
  • dA, dB: Doses of Drug A and Drug B in the combination.
  • DA, DB: Standalone equipotent doses (e.g., IC₅₀ or MIC).

Expected Excel Format

The uploaded Excel file should have columns matching:

Sample_ID, Dose_A, Dose_B, Solo_DA, Solo_DB
